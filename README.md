# TagManager--文件标签管理器

一个轻量的本地文件标签管理工具。给文件打上标签，之后按标签快速筛选、搜索和打开文件。

基于 **WinUI 3** 构建，界面风格与 Windows 11 一致，数据保存在本地 SQLite 数据库中。

---

## 功能特性

### 文件与标签
- 添加任意本地文件，为每个文件打上（多个）标签
- 支持多选文件，一键批量添加 / 移除标签
- 标签输入框带自动补全，输入时提示已有标签
- 双击文件项直接用系统默认程序打开

### 查看与筛选
- “所有文件”页：查看全部记录，支持搜索文件名、路径或标签
- “按标签查看”页：多选标签，显示同时拥有这些标签的文件（交集）
- 排序方式：名称 A-Z / Z-A、修改时间新→旧 / 旧→新
- 搜索与标签筛选、排序可叠加生效

### 标签管理
- 列出所有标签及关联文件数量
- 重命名、删除、合并标签
- 为标签设置颜色，列表中会显示对应颜色
- 合并标签时自动迁移颜色

### 界面与体验
- 现代化竖条导航（NavigationView）
- 浅色 / 深色 / 跟随系统主题切换
- 文件列表显示系统图标
- 文件项右键菜单：打开、打开所在文件夹、复制路径、复制文件名、删除记录
- 标签项右键菜单：设置颜色、重命名、删除、合并到

### 数据
- 使用 SQLite 存储，文件为 `tagmgr.db`
- 支持导出为备份文件，或从备份文件导入恢复
- 数据保存在本地虚拟化路径

## 📖 使用说明

### 添加文件
1. 进入“所有文件”页
2. 点击“选择文件...”，选择一个或多个文件
3. 文件会出现在左侧列表中

### 打标签
1. 在左侧单击选中文件（`Ctrl` 多选，`Shift` 连选）
2. 在右侧输入框输入标签，支持自动补全
3. 点击“给选中文件添加标签”，或直接按回车
4. 标签会显示在文件下方

### 按标签查看
1. 进入“按标签查看”页
2. 在左侧选择一个或多个标签
3. 右侧显示同时拥有这些标签的文件
4. 可在右上角进一步搜索或排序

### 管理标签
1. 进入“标签管理”页
2. 可搜索标签、查看关联文件数
3. 选中标签后，使用底部按钮或右键菜单进行重命名、删除、合并、设置颜色

### 备份与恢复
- **设置 → 导出数据...**：将当前数据库保存为 `.db` 备份文件
- **设置 → 导入数据...**：从备份文件恢复（会覆盖当前数据）
